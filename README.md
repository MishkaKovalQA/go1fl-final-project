# Планировщик задач (TODO)

Веб-сервер планировщика задач - дипломный проект курса Яндекс Практикум Go.
Позволяет добавлять, редактировать, удалять задачи и отмечать их выполненными.
Задачи могут повторяться по правилу (ежедневно, ежегодно, по дням недели/месяца).

Директория `tests` содержит тесты для проверки API, `web` - файлы фронтенда.

## Возможности

- Добавление, просмотр, редактирование, удаление задач
- Отметка о выполнении (повторяющиеся задачи переносятся на следующую дату)
- Правила повторения задач

## Выполненные задания со звёздочкой

- Полная поддержка правил повторения `w` (дни недели) и `m` (дни месяца, включая последний/предпоследний день и указание месяцев)
- Определение порта через переменную окружения `TODO_PORT`
- Определение пути к БД через `TODO_DBFILE`
- Поиск задач по тексту и по дате (`/api/tasks?search=`)
- Аутентификация по паролю (JWT, `TODO_PASSWORD`)
- Docker-образ (Dockerfile + запуск с базой на хосте)

## Запуск

Требуется Go 1.24+.

```
go mod download
go run main.go
```

Сервер стартует на порту 7540. Откройте http://localhost:7540

## Переменные окружения

| Переменная      | Назначение                       | По умолчанию   |
|-----------------|----------------------------------|----------------|
| `TODO_PORT`     | Порт веб-сервера                 | `7540`         |
| `TODO_DBFILE`   | Путь к файлу базы данных SQLite  | `scheduler.db` |
| `TODO_PASSWORD` | Пароль для входа (если задан)    | не задан       |

Если `TODO_PASSWORD` не задан, аутентификация отключена.

## Тесты

```
go test ./tests
```

Флаги в `tests/settings.go`:
- `FullNextDate = true` - проверка правил `w` и `m`
- `Search = true` - проверка поиска
- `Token` - токен для тестов с аутентификацией (получить через `/api/signin`)

## Аутентификация

Задайте пароль через `TODO_PASSWORD` при запуске. Войдите через
http://localhost:7540/login.html - сервер вернёт JWT-токен, который
сохраняется в куке и проверяется при обращении к API.

## Docker

Сборка образа:

```
docker build -t todo-scheduler .
```

Запуск с сохранением базы на хосте:

```
# Linux/macOS
docker run -d -p 7540:7540 \
  -v "$(pwd)/data:/data" \
  -e TODO_DBFILE=/data/scheduler.db \
  --name todo todo-scheduler

# Windows (Git Bash)
MSYS_NO_PATHCONV=1 docker run -d -p 7540:7540 \
  -v "/c/путь/к/проекту/data:/data" \
  -e TODO_DBFILE=/data/scheduler.db \
  --name todo todo-scheduler
```

С паролем добавьте `-e TODO_PASSWORD=ваш_пароль`.

База данных сохраняется в примонтированной папке `data/` на хосте.

## Структура

- `main.go` - точка входа
- `pkg/server` - запуск веб-сервера
- `pkg/api` - обработчики API
- `pkg/db` - работа с базой данных SQLite
- `web` - фронтенд
- `tests` - тесты
